## 👋 About Me

I’m a **backend-focused developer** who believes in **strong fundamentals, clean architecture, and scalable systems**.  
I enjoy working close to the system — writing efficient code, understanding how things work under the hood, and building APIs that actually hold up under load.

- 💻 Comfortable with **low-level & high-level languages**
- ⚙️ Strong focus on **backend systems & APIs**
- 🐳 Prefer **Dockerized**, production-style setups
- 🐧 Linux user — CLI over GUI, always
- 📦 Databases, caching & performance optimization excite me

I believe good software is built the **traditional way**:  
> solid basics → clear logic → real-world constraints → then optimization.
